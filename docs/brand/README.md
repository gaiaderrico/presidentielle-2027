# Brand: polis

Original files from the designer are in this folder. The files the app can use are in `public/brand/` and are served from `/brand/...`.

## Originals

| File | What |
|---|---|
| `F1-horizontal-lockup.pdf` | Full mark + "polis" wordmark |
| `F2-app-icon.pdf` | App icon (icon mark on a white tile) |
| `F3-small-size-check.pdf` | The two marks at 112, 64 and 32 px |

The PDFs only contain JPEG images, not vectors. Ask the designer for SVG files if we need a vector logo.

## Files for the app (`public/brand/`)

All logos are `#111111` on a transparent background. Each one also has a `-white` version for dark backgrounds.

| File | Size | Use it for |
|---|---|---|
| `polis-lockup.png` | 1655 × 582 | Logo with the name: header, landing page, share images |
| `polis-mark.png` | 723 × 582 | Full mark (5 columns, 2 steps). Large sizes only |
| `polis-icon-mark.png` | 914 × 754 | Icon mark (3 columns, 1 step). Use it at 64 px and below (see F3) |
| `polis-app-icon.png` | 1024 × 1024 | Square app icon, white background, no rounded corners (phones add them) |

In the code, the path is the file name under `/brand/`, for example `/brand/polis-lockup.png`.
